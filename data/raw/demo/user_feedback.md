# Fictional feedback snippets — synthetic, not real research

**Provenance:** invented examples written solely to demonstrate the analysis
workflow. These are not public reviews, real user quotations, interview
transcripts, or evidence of demand or prevalence.

1. Fictional trial user A: “I wasn't sure which photos would be shared with my
   family.”
2. Fictional trial user B: “I wanted to know what happens to my files after the
   trial ends.”
3. Fictional trial user C: “I already have cloud storage, so I don't see what
   is different here.”
4. Fictional trial user D: “I could not tell whether the trial would start a
   paid subscription automatically.”

These snippets suggest questions about sharing permissions, differentiation,
and trial-to-paid terms. They do not establish that real users have these
barriers, how often they occur, or whether resolving them changes conversion.
