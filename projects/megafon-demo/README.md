# Учебный кейс «Связь для близких и собственных устройств»

Этот отдельный проект разбирает открытый конкурсный бриф, переданный пользователем. В самом брифе описан **вымышленный мобильный оператор**, а все значения названы учебными. Материалы не являются данными или исследованием реального МегаФона.

- Утверждённая рамка: [`brief.md`](brief.md)
- План исследования: [`research_plan.md`](research_plan.md)
- Варианты: [`options.md`](options.md)
- Пять обязательных частей: [`MEGAFON_STRATEGY_PACK.md`](MEGAFON_STRATEGY_PACK.md)
- Проверяемая стратегия: [`strategy.md`](strategy.md)
- Экономический порог и результат: [`economics_input.json`](economics_input.json), [`economics_result.json`](economics_result.json)
- Источник и provenance: [`sources/`](sources/)
- Состояние решения и тестовый реестр: [`state/`](state/)

Цифры исходного брифа используются только для анализа учебного сценария. Неизвестные частоты проблем, спрос, удержание, затраты, размер выборки и продуктовые возможности не заменяются вымышленными наблюдениями.
